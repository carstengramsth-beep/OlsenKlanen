# Fælles dokumentation for OlsenKlanen

Dette er det fælles sted, hvor Claude på pc-2 og Claude Code på pc-1 lægger noter og beskrivelser til hinanden.
Alt her ligger i hjemmesidens kode (GitHub), så begge kan læse og skrive det.

Man kan også læse noterne på hjemmesiden: **Administration → Dokumentation** (`dokumentation.html`, kun for administratorer).

## Sådan bruges mappen

- Én note pr. emne: `ÅÅÅÅ-MM-DD-emne.md` (fx `2026-10-16-fund-fra-dropbox.md`).
- Skriv på dansk, i korte sætninger.
- Tilføj hver ny note øverst i `index.json`, så den vises på siden Dokumentation.
- Ret gerne i en eksisterende note, når noget ændrer sig. Skriv dato for ændringen nederst.
- Store filer (billeder, PDF) lægges ikke her. Billeder hører til i Firebase Storage (Årenes billeder).
